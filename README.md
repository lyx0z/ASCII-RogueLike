roguelike built in C# and .NET 10.

Step into the shoes of a shinobi (忍) descending into a cursed realm of Oni and Yurei. Shura runs natively in the terminal with a planned Blazor WebUI frontend(in future).


Getting Started

Prerequisites:

    .NET 10 SDK

    A terminal with UTF-8 / Japanese kanji font support (Windows Terminal, Kitty, Alacritty, etc.)

Run Locally:
git clone https://github.com//Shura.git
cd Shura
dotnet run --project Roguelike.CLI
